# Clustered OB + MSS + FVG

`Clustered_OB_MSS_FVG.pine` is a standalone TradingView Pine Script v6 overlay indicator. It visualizes structural clusters for historical review. It is not a strategy, does not produce entries or exits, and has no dependency on the AI Futures Trading Lab.

## What constitutes a cluster

A cluster is created only after one causal directional event establishes all of the following:

1. A close-confirmed break of a confirmed swing (MSS).
2. The uninterrupted displacement suffix that ends on the MSS bar.
3. The opposing candle immediately before that displacement (OB).
4. A standard three-candle FVG generated inside that displacement.

The causal flow is MSS → identify its responsible displacement → identify that displacement's anchor/OB → identify an FVG generated by the same displacement → validate → render. No component is rendered independently.

## Detection

### MSS

`MSS Swing Length` controls both sides of `ta.pivothigh()` and `ta.pivotlow()`. A pivot becomes available only after its right-side confirmation bars have closed. A bullish MSS requires a confirmed close above the latest unbroken confirmed swing high; a bearish MSS requires a confirmed close below the latest unbroken confirmed swing low. Each swing can break once.

### Order block

The implementation first identifies displacement, not the OB. Displacement is the maximal uninterrupted suffix ending on the MSS bar where every candle:

- has a body in the MSS direction; and
- closes beyond the preceding candle's directional extreme (above its high for bullish displacement, below its low for bearish displacement).

At least two displacement candles are required. The first candle that fails either rule terminates the leg. This makes opposing candles, dojis, inside closes, and weak continuation bars explicit event boundaries instead of allowing separate delivery legs to be stitched together.

Only the candle immediately before the displacement start can be the OB. It must be bearish for bullish displacement or bullish for bearish displacement. Its full high-to-low range is drawn. If that exact anchor is not opposing, the candidate is discarded; the script does not search farther backward for a convenient OB.

### Fair value gap

- Bullish: candle 1 high is below candle 3 low.
- Bearish: candle 1 low is above candle 3 high.

The FVG's right candle must fall inside the identified displacement, and its left candle cannot predate the displacement-anchor OB. Because every displacement candle already satisfies the directional impulse rule, the gap is generated by the same leg that closes through the swing. An older gap outside that exact leg is ineligible even if it is fewer than 12 bars away.

If the displacement generates multiple FVGs, the earliest qualifying FVG in the leg is selected. This is chronological and reproducible. The FVG must exist by the MSS close; the script does not wait after the MSS and attach a later gap.

The internal 12-bar maximum is a safety/resource boundary only. It is not the association definition. The uninterrupted displacement rules determine the event boundary first.

## Display Mode

`Display Mode` changes visualization only. It does not change cluster detection, association, qualification, mitigation, or historical processing.

- `Latest Cluster` is the default and is intended for clean discretionary chart review. When a new cluster confirms, the prior cluster's OB box, FVG box, MSS line, and MSS label are deleted, then the new cluster is rendered. Older logical cluster records remain stored and continue through mitigation processing.
- `All Clusters` is intended for historical inspection and validation. Every retained cluster is rendered under the existing 100-cluster storage policy.

Changing the input makes TradingView recalculate the script from the beginning. Latest mode therefore rebuilds with only the final confirmed cluster visible, while All mode rebuilds all retained cluster drawings without stale objects from the previous setting.

## Time-window qualification

`Use Time Window` defaults off. Start and end are entered as separate hour/minute controls and use a half-open interval: start is included and end is excluded. Equal start and end values mean all day; an end earlier than the start creates an overnight window.

The MSS bar is qualified in the configured `Time Zone`. The default `America/New_York` IANA zone follows historical US daylight-saving rules in TradingView. A cluster that qualifies within the window continues after the window closes; the window is not a rendering filter.

## Mitigation and extension

A zone is mitigated on its first bar *after cluster creation* whose high-low range intersects that zone. Delaying mitigation checks until the next bar prevents a formation bar from immediately mitigating its own FVG.

- `Extend` off: the OB ends after its source candle and the FVG ends after its third candle.
- `Extend` on: both boxes extend through the current bar.
- `Extend` and `Extend Until Mitigated` on: each box stops independently on its first post-creation touch.

The cluster enters its mitigated state after both zones have been touched.

## Historical behavior and object management

Historical and realtime bars execute the same close-confirmed logic. There is no `request.security()`, lookahead mode, future-bar inspection, or visible-range API. The only latency is the intentional swing confirmation delay.

The indicator retains at most 100 logical clusters in either display mode. When capacity is reached, it removes the oldest fully mitigated cluster. If all 100 remain active, it preserves them and skips a new cluster rather than deleting active structure. Latest mode normally has only four live drawing objects even though older logical records remain available for state processing.

## Known limitations

- The strict displacement rule favors causal reproducibility over discretionary visual interpretation and will reject weaker or interrupted moves a trader might still describe as displacement.
- A close, rather than a wick, must break the swing level.
- Time qualification uses the chart bar's opening timestamp and is intended for intraday charts.
- Only the earliest qualifying FVG in the identified displacement is drawn.
- A later settings change causes TradingView to recalculate the indicator, as with any Pine script.
- Final compilation and visual inspection must be performed in TradingView because this workspace has no hosted Pine compiler or chart renderer.
